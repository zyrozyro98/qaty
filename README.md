# تطبيق قات - بيع وتوصيل القات

تطبيق اندرويد كامل مع دعم اللغة العربية، نظام إدارة متكامل، وواجهة API متطورة.

## 📱 ميزات التطبيق

### للمستخدمين
- ✅ تسجيل الدخول والتسجيل بأنواع مختلفة (مشتري، بائع، مندوب توصيل)
- ✅ تصفح المنتجات وشرائها مع خيار غسل القات (+100 ريال)
- ✅ نظام طلبات متكامل مع تتبع الحالة
- ✅ محفظة إلكترونية متعددة الخيارات
- ✅ تقييم البائعين والمنتجات والخدمات
- ✅ إشعارات فورية لجميع الأحداث

### للبائعين
- ✅ إدارة المنتجات (إضافة، تعديل، حذف)
- ✅ متابعة الطلبات والمبيعات
- ✅ نظام سحب الأرباح
- ✅ شراء باقات إعلانية

### للمدير
- ✅ لوحة تحكم كاملة مع إحصائيات مفصلة
- ✅ إدارة جميع المستخدمين
- ✅ إدارة الأسواق ومغاسل القات
- ✅ إدارة باقات الإعلانات
- ✅ إنشاء أكواد هدايا
- ✅ معالجة طلبات السحب
- ✅ تهيئة النظام ببيانات أولية
