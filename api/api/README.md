# تطبيق Qaty - نظام بيع وتوصيل القات

## نظرة عامة
تطبيق متكامل لإدارة بيع وتوصيل القات في اليمن، مع نظام متكامل للمشترين والبائعين والسائقين وإدارة المغاسل.

## المميزات الرئيسية

### للمشترين:
- تصفح المنتجات حسب الفئة والسوق
- إضافة منتجات للسلة مع خيار الغسيل (+100 ريال)
- دفع عبر المحفظة الإلكترونية
- متابعة حالة الطلبات
- تقييم البائعين والمنتجات
- شحن الرصيد عبر محافظ إلكترونية متعددة

### للبائعين:
- إضافة وتعديل منتجاتهم
- متابعة طلبات البيع
- استلام إشعارات الطلبات الجديدة
- توليد رموز بيع للمنتجات
- سحب الأرباح عبر محافظ إلكترونية

### للسائقين:
- استلام إشعارات طلبات التوصيل
- تحديث حالة التوصيل
- متابعة الطلبات المسندة إليهم

### للمديرين:
- إدارة جميع المستخدمين
- إدارة الأسواق ومحطات الغسيل
- إدارة الباقات الإعلانية
- الموافقة على طلبات السحب
- إنشاء أكواد الهدايا
- إحصائيات شاملة للنظام

## التقنيات المستخدمة

### Backend (Python/Flask):
- Flask + Flask-SQLAlchemy
- Flask-JWT للتوثيق
- Flask-SocketIO للإشعارات الفورية
- PostgreSQL (على Render)

### Android App (Python/Kivy):
- Kivy + KivyMD
- تخزين محلي باستخدام JsonStore
- اتصال REST API

### النشر:
- Render.com للخادم وقاعدة البيانات
- GitHub للتحكم بالإصدارات
